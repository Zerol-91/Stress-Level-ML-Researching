# AGENTS.md

Jupyter-notebook-only ML research repo (no package, no tests, no CI, no `requirements.txt` — deps are installed per-notebook via `%pip install`). Notebooks are the source of truth; most research notes/markdown are in **Russian** (keep that when editing them). Convention: commit notebooks with outputs after a successful run (`git log` shows "delete outputs" → "run research" cycles).

## Pipeline (ordered)

1. `Anxiety_Level_Test_2.csv` — raw Google Forms export at repo root.
2. `notebooks/01_data_preprocessing.ipynb` — renames columns, encodes GAD-7 answers, computes `Anxiety_Level` = GAD-7 sum (0–21), saves `data/processed_data.csv`.
3. All other notebooks read `data/processed_data.csv`. **Re-run 01 whenever the raw CSV changes.**

- Target is `Anxiety_Level`. `Subjective_Anxiety` (1–10 self-report) is deliberately excluded from features and used only for GAD-7 correlation analysis (r≈0.70, see `03_model_evaluation`).
- Current best: CatBoost tuned with Optuna (MAE 2.79, R² 0.39 — the published ground truth, BSUIR BIG DATA 2026 paper; README). Log-target, bagging and SMOGN were tested and rejected (degraded metrics).

## Gotchas

- **Cyrillic filename**: `notebooks/02с_smote_stress_prediction.ipynb` — the `с` is Cyrillic U+0441, not ASCII `c`. Typed paths like `02c_...` will not resolve.
- **`02` vs `02с` are near-duplicates** of the same model run (Ridge, RF, LightGBM, CatBoost + Optuna, bagging, log-target, SHAP). `02с` additionally applies **SMOGN** (regression oversampling via `smogn` package, `%pip install -q smogn`) despite the misleading filename. Keep both.
- **Colab path defaults**: `02_stress_prediction`, `02с_...`, and `03_model_evaluation` read data/models from `/content/drive/MyDrive/` via `EXTRA_FILE_PATH` / `EXTRA_PATH` / `FILE_PATH` variables (commented local alternatives). Edit those to run locally. `01b_data_eda` uses `'../data\processed_data.csv'` with a backslash — fine on Linux, breaks on Windows.
- **`.gitignore` traps CSVs**: `*.csv` and `data/raw/`, `data/external/` are ignored; the two existing CSVs are force-tracked. New CSVs will not appear in `git status` — add with `git add -f`. `mlruns/`, `mlartifacts/` are ignored too.
- **MLflow/DagsHub**: `02b_mlflow_tracking.ipynb` logs to the DagsHub remote (`https://dagshub.com/Zerol-91/Stress-Level-ML-Researching.mlflow`, experiment `Anxiety_Prediction`); needs `MLFLOW_TRACKING_USERNAME`/`MLFLOW_TRACKING_PASSWORD` env vars. Code degrades gracefully (try/except) when unreachable. The old root `Anxiety_Level_Baseline (2).ipynb` sets up dagshub in-cell too.
- `03_model_evaluation` loads the saved model with `joblib` from `models/best_model.pkl` — that path is generated by earlier notebooks and gitignored (`/models`).
